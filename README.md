# 🛠️ Ferramentas do Suporte

Bem-vindo ao repositório **Ferramentas do Suporte**.

Este repositório centraliza utilitários utilizados no dia a dia da equipe de suporte técnico, com o objetivo de aumentar a produtividade, agilizar atendimentos e facilitar atividades de diagnóstico e acesso remoto.

# 📦 Ferramentas Disponíveis

<details>
<summary><b>🤖 Claude Setup</b></summary>

### Arquivo
`Claude Setup.exe`

### Objetivo
Instalação do Claude Desktop para utilização de inteligência artificial em atividades de suporte, análise de logs, documentação e produtividade.

### Principais recursos
- Análise de arquivos e logs
- Auxílio na criação de documentações
- Sugestões de scripts
- Apoio em troubleshooting

</details>

---

<details>
<summary><b>🖥️ Remote Desktop Connection Manager</b></summary>

### Arquivo
`Remote Desktop Connection Manager.zip`

### Objetivo
Gerenciar múltiplas conexões RDP em um único local.

### Benefícios
- Organização de acessos remotos
- Agrupamento de servidores
- Centralização de credenciais
- Abertura rápida de conexões

### Indicado para
- Suporte N1
- Suporte N2
- Administradores de Sistemas

</details>

---

<details>
<summary><b>🎨 LightShot</b></summary>

### Arquivo
`setup-lightshot_captura de tela.exe`

### Objetivo
Captura rápida de telas para evidências técnicas e documentação.

### Recursos
- Captura parcial da tela
- Edição rápida
- Inserção de setas e marcações
- Compartilhamento de imagens

### Casos de uso
- Evidências para chamados
- Homologações
- Documentação de erros

</details>

---

<details>
<summary><b>📡 NPP (Notepad++)</b></summary>

### Arquivo
`npp.8.9.6.2.Installer.x64.exe`

### Objetivo
Editor avançado para análise e edição de arquivos texto.

### Recursos
- Destaque de sintaxe
- Pesquisa avançada
- Comparação de arquivos
- Manipulação de logs

### Utilização comum
- Arquivos TXT
- Logs de aplicação
- XML
- JSON
- SQL

</details>

# 💻 Requisitos

- Windows 10 ou superior
- Permissão para instalação de softwares
- Acesso à rede corporativa quando necessário

# 🚀 Como Utilizar

1. Faça o download do arquivo desejado.
2. Execute o instalador.
3. Siga as instruções da instalação.
4. Utilize a ferramenta conforme sua necessidade operacional.
